Domain-Sperre

Ohne Eintrag beantwortet die Anlage Anfragen für jeden beliebigen Domainnamen, der zufällig hierher zeigt — auch für eine fremde Domain, die absichtlich hierher gerichtet wurde. Mit der echten Domain eingetragen, wird jede Anfrage mit einem anderen Namen abgelehnt. Mehrere Namen durch Komma trennen. Für eine rein lokale Anlage kann das Feld leer bleiben.

Sie greifen gerade über {{.CurrentHost}} zu. Dieser Name muss in der Liste stehen, sonst wird die Eingabe abgelehnt — sonst wäre genau diese Seite anschließend nicht mehr erreichbar. Wirkt erst nach einem Neustart des Dienstes (Schaltfläche auf der Seite Backup).

Reverse-Proxy

Einschalten, wenn vor dieser Anlage ein Reverse-Proxy die Verschlüsselung übernimmt (z. B. Plesk mit nginx, siehe deploy/plesk-nginx-directives.conf). Nur dann werden dessen Angaben zur echten Herkunft eines Zugriffs ausgewertet — ohne Proxy davor könnte sich sonst jeder Aufrufer eine beliebige Adresse zuschreiben. Wirkt sofort.

Diese Seite wurde gerade {{if .RequestIsHTTPS}}verschlüsselt (HTTPS) abgerufen — das Sitzungs-Cookie wird entsprechend als „nur über HTTPS" markiert.{{else}}unverschlüsselt (HTTP) abgerufen. Für eine rein lokale Anlage ist das in Ordnung. Ist die Anlage dagegen aus dem Internet erreichbar, sollte hier HTTPS stehen — steht ein Proxy davor, der TLS beendet, muss dafür die Einstellung oben eingeschaltet sein.{{end}}
