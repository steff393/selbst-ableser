So geht’s

  1. Seite öffnen: den QR-Code mit der Kamera des Smartphones scannen — der Zugangscode ist dann schon eingetragen. Oder die Adresse im Browser eingeben und den Code abtippen; Groß- und Kleinschreibung spielen keine Rolle.
  2. Auf „Anmelden“ tippen. Mit einem Haken bei „Auf diesem Gerät merken“ ist der Code beim nächsten Mal schon eingetragen.
  3. Sie sehen den Verbrauch Ihrer Wohnung für jeden Monat, im Vergleich zum Vormonat, zum Vorjahresmonat und zum Durchschnitt.

Gut zu wissen

  • Der Code gilt nur für Ihre Wohnung und nur für Ihre Mietzeit. Bitte bewahren Sie dieses Schreiben auf und geben Sie den Code nicht weiter.
  • Ist der Code verloren gegangen oder in fremde Hände geraten, melden Sie sich bitte. Er wird dann gesperrt, und Sie erhalten einen neuen.
  • Die Werte informieren Sie über Ihren Verbrauch; sie sind keine Abrechnung.
  • Sobald eine neue Monatsinformation vorliegt, bekommen Sie zusätzlich eine kurze E-Mail.
